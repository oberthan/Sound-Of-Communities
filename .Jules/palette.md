## 2025-05-15 - [Search Bar Enhancements]
**Learning:** In WPF, using a `MultiDataTrigger` to manage placeholder visibility (showing it only when the `TextBox` is empty AND not focused) provides a cleaner UX than simple placeholders, as it avoids visual clutter when the user is ready to type.
**Action:** Use `MultiDataTrigger` on an overlay `TextBlock` for accessible placeholders in future WPF projects.
